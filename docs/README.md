# Bacco Perbacco — Sito trattoria

Sito dinamico per la trattoria italiana **Bacco Perbacco**.

## Stack

- **Backend:** Express (`backend/`) — API `/api/health`, `/api/restaurant`
- **Frontend:** React + Vite (`src/`) — home di presentazione
- **Static:** logo e asset in `public/assets/`

## Avvio

```bash
npm run install:all
npm run dev
```

- Frontend: http://localhost:5173  
- API: http://localhost:5000/api/health  

## Struttura attuale

Focus sulla **home page di presentazione** brand-first. Auth, CRUD e altre pagine arriveranno dopo.
